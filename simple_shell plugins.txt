каждый плагин должен быть помещен в "plugins_ss"

в ".simple_shell_settings.json" должен быть расположен словарь "plugin" в нем храняться префиксы и имена плагинов(без ".py")

"plugin": {
    "_test_": "test"
}

важно чтобы перфикс плагина не пересекался с системными и prefix_run (порядок загрузки системные -> prefix_run -> plugin)

плагины исполняються в двух режимах global и local
в global плагин имеет полный доступ к переменным simple_shell
в local только к внутреним

в плагин передаються command_prefix, command_arg_int, command_arg, plugin
каждый плагин должен иметь функцию dispatch_plugin(точка входа в плагин)

пример плагина

command_prefix = None
command_arg_int = None
command_arg = None


def dispatch_plugin():
    print(command_prefix)
    print(command_arg_int)
    print(command_arg)

чтобы плагин мог переопределять переменные simple_shell
для этого надо включить глобальный мод и прописать например такую конструкцию
def dispatch_plugin():
    try:
        main_globals["simple_shell"] = "555>>>"# main_globals передаеться только в том случае если включен глобальный мод
    except NameError:
        print("local")


ss_api если в настройках включена эта функция то плагину будет передан словарь "ss_api"

полный список api:

    err = ss_api["err"]
    bs = ss_api["bs"]
    YELLOW = ss_api["YELLOW"]
    settings = ss_api["settings"]
    simple_shell = ss_api["simple_shell"]
    script_dir = ss_api["script_dir"]
    script_file = ss_api["script_file"]
    pyt_lex = ss_api["pyt_lex"]
    post = ss_api["post"]
    PFT = ss_api["PFT"]
    command_separators = ss_api["command_separators"]

err, bs, YELLOW - ansi цвета для вывода (err - красный, bs - белый, YELLOW - желтый)
settings - полный словарь настроек
simple_shell - приглашение simple_shell
script_dir - папка в которой находиться скрипт
script_file - путь к стороннему скрипту(может быть None)
pyt_lex - встроенный лексер simple_shell(экземляр класса)
post - система кодирования ошибок
PFT - вывод с подстветкой
command_separators - встроеный pipeline simple_shell (внимание использовать только передавая 1 аргумент, аргумент plugin передавать нельзя(может вызвать рекурсию и post_code: 19)) возрашает массив типа [[_test_],[6]](ввод был _test_ _&_ 6)
