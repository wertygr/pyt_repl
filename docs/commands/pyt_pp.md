multiline editor\

```pycon
_pyt++_ <flags>
```

**flag:**

| flag      |                                  description |
|:----------|---------------------------------------------:|
| old       |                                   load cache |
| save      | save file in ./pyt_save/%Y_%m_%d_%H_%M_%S.py |
| eval      |                                              |
| not_exec  |                             not execute code |
| not_cache |                         do not save to cache |
| paste     |                              paste to buffer |
| copy      |                             copy from buffer |
